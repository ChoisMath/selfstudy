# 안내 영상 문장 끝 여백·페이드 수정

## 목표와 범위

교사·학생·학년관리자 3편의 원고, 기존 목소리, 화면 내용을 유지하면서 191문장 끝에 0.5초 qsin 페이드아웃과 1초 후행 무음을 적용한다. 기존 0.2초 문장 간 간격은 유지하여 실제 쉼은 약 1.2초다.

## 확인한 원인

기존 후처리는 앞 -40dB·뒤 -45dB 트림과 0.5초 꼬리 무음뿐이며 페이드가 없다. 191개 raw WAV가 모두 남아 있어 TTS 재생성이 불필요하다. 기존 생성 명령은 무음 설정이 바뀌면 캐시가 무효화돼 재합성하므로 raw 전용 --reprocess 경로를 추가한다.

## 실행과 검증

1. 기존 3개 MP4·문장/장면 MP3·manifest·길이 JSON을 out/before-audio-tail-20260919-180746에 백업하고 raw SHA256을 기록한다.
2. 전체 입력 preflight를 통과한 뒤 기존 트림 → 마지막 0.5초 fade → 1초 pad 순서로 처리한다. cache에 fade 조건을 반영하고 raw·원고·기존 전사 기록을 보존한다.
3. 기존 PCM 경유 장면 결합과 길이 JSON 갱신을 사용한다. 새 MP4는 임시 출력에서 완성·검증한 뒤 요청 파일명으로 교체한다.
4. core 회귀 테스트, ffmpeg 실제 fade·무음 검사, 191개 문장·50개 장면 길이 일치, 원고/원본 raw 해시 보존, 영상 스트림·전체 디코딩·대표 프레임을 확인한다.
5. README·프로젝트 지도·공유 인계/작업일지에 결과를 기록한다. YouTube 업로드와 기존 웹사이트의 영상 ID/구간 링크는 변경하지 않는다.

## 독립 검토

narration_audio_audit 탐색 에이전트가 raw 전체 존재, 캐시 무효화의 재합성 위험, PCM 경유 필요성, fade 곡선과 무음 길이를 확인했다. 마지막 음절을 더 급격하게 낮추는 선형 fade 대신 초반 감쇠가 완만한 qsin을 사용한다. 구현 후 다시 검토한다.
