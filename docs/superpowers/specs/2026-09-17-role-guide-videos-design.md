# 역할별 안내 영상 3편 + 안내 페이지 5개 설계

- 날짜: 2026-09-17
- 기준 문서: `.claude/GUIDE_PAGES.md` (절차 `/guide-page`), 영상 도구 `demo-video/README.md`
- 상태: 설계 승인(1~5절), 원고는 초안 — 음성 청취 확인 단계에서 문장 단위로 다시 다듬는다

## 1. 목표와 범위

교사(감독교사+담임교사)·학생·학년관리자에게 각자 할 일을 따라 할 수 있게 보여주는 **Chois 클론 음성 안내 영상 3편**과, 같은 장면 스틸로 만든 **안내 페이지 5개**를 만든다. 영상 길이 제한은 두지 않고 기능을 빠짐없이 자세히 안내한다.

| 결과물 | 내용 |
|---|---|
| 선행 수정 2건 | 비담임 교사 비밀번호 변경 차단, 학년관리자 학생 템플릿 다운로드 차단 (3절) |
| 영상 | `TeacherGuide`(21장면) · `StudentGuide`(11장면) · `GradeAdminGuide`(18장면) — `demo-video/out/*.mp4` |
| 안내 페이지 | `/help/attendance` · `/help/homeroom` · `/help/student` · `/help/grade-admin` · `/help/seats` |
| 화면 연결 | 각 화면 `?` 버튼(새 탭) + `/help` 허브 링크 + YouTube 영상 카드 |

**비목표**
- 전체관리자(`/admin/*`) 안내
- 학생 Excel 재업로드 동작(같은 반·번호면 기존 학생 비활성화 후 새로 생성) 변경 — 영상에서 주의 사항으로만 안내
- 출석부 회색 좌석을 **마우스로** 길게 누르면 활성화와 동시에 클릭(출석)까지 발생하는 문제 — 영상은 폰(터치) 기준이라 범위 밖, 후속 과제로 기록
- 2학년 야간 미래홀 도면 목업 — 가상 데이터는 1학년 기준

### 요청과 실제 동작이 다른 점 — 원고는 실제 동작 기준

- 출석부 4번째 탭 이름은 **"불참신청"**이다(요청의 "불참승인" 아님).
- 감독 교체 화면은 **"감독일정"**(`/homeroom/schedule`)이다. 비담임 교사는 출석부 헤더 "감독일정" 버튼으로, 담임은 "담임교사" → 감독일정 탭으로 들어간다. 모든 교사가 오늘 이후의 어떤 배정이든 교체할 수 있고, 한 방향 교체이며, 그날 3블록이 함께 바뀐다.
- 담임 "학생관리" 탭은 실제로 **우리 반 주간 출결표**다.
- 학생이 참여일정 요일 칸을 누르면 페이지 이동이 아니라 **같은 화면이 "불참 신청하기" 신청서로 바뀐다**.
- 참여설정에 "활성화 버튼"은 없다. **참가 체크박스**(그 시간 전체) · **요일 버튼**(요일별) · **방과후 체크박스**(그 요일 노란 방과후 좌석)다. "꾹 눌러 활성화"는 출석부 회색 좌석 동작으로 따로 안내한다.
- 도우미는 반당 1명 제한이 없는 **학생별 토글**이고, 학생에게 생기는 탭은 **"일괄신청"**이다. 같은 반·**오늘 날짜만**, 사유는 학원·방과후·질병. 지정 후 **다시 로그인해야** 탭이 보인다.
- 감독 "누계" 버튼은 교사별 월별 횟수 **모달**(Excel 없음)이고, Excel 누계는 달력 **Excel** 버튼 파일의 **"누계" 시트**다.
- 학년관리 허브 탭 라벨은 `오늘출결` · `학생 관리` · `참여 설정` · `좌석 배치` · `감독 배정` · `월간출결`(가운데 4개 띄어쓰기)이고 URL이 바뀌지 않는 클라이언트 탭이다.
- 담임이 **불참사유등록**으로 넣은 결석은 출석부 좌석에서 노랑이 아니라 **빨간 결석**이다(노란 "불참승인"은 승인된 신청만).
- "NEIS 로그인 아이디 / 초기 비밀번호 1111"은 코드에 근거가 없는 운영 방침이다(예전 `/help`에는 1234로 적혀 있었다). 사용자 지시대로 1111로 안내한다.

## 5. 교사 영상 `TeacherGuide` (21장면)

폰 장면: 1~10, PC 장면: 11~21. 문장은 자막 표기, 숫자·영문 음성 읽기는 `SPOKEN`(예: self.posan.kr → "셀프 점 포산 점 케이알", NEIS → "나이스", 1111 → "일일일일", i → "아이", Excel → "엑셀").

| # | id | 화면 상태 | 내레이션 초안 |
|---|---|---|---|
| 1 | Intro | 제목 카드 + 목차 칩 | 포산고 자율학습 출석부, 교사 사용 안내입니다. / 로그인부터 출석 체크, 불참신청 승인, 감독 교체, 그리고 담임교사 메뉴까지 차례로 살펴보겠습니다. |
