# /help 사용설명서 페이지 설계

> 작성일: 2026-04-09

## 목적

포산고 자율학습 출석부 시스템의 사용설명서 페이지를 제공한다. 첫 접속자에게 이 URL을 안내하여 로그인 없이도 앱 설치, 로그인, 역할별 기능 사용법을 확인할 수 있게 한다.

## 라우팅 및 접근

- **경로**: `/help`
- **인증**: 불필요 (공개 페이지)
- **미들웨어 수정**: `src/middleware.ts`에서 `pathname.startsWith("/help")`를 공개 경로에 추가
- **파일**: `src/app/help/page.tsx` (클라이언트 컴포넌트, 단일 파일)

## 레이아웃

### 헤더 (고정, 상단)
- 배경: `#1e40af` (기존 앱 테마 컬러)
- 좌측: 포산고 로고(`/posan.svg`) + "포산고 자율학습 안내" 타이틀
- 우측: 햄버거 메뉴 버튼(☰ / ✕ 토글)

### 목차 사이드바 (오버레이)
- 트리거: 헤더 우측 햄버거 버튼
- 동작: 우측에서 슬라이드 인/아웃 (CSS transition, transform)
- 배경 딤: `rgba(0,0,0,0.3)` 오버레이, 클릭 시 닫힘
- 너비: 280px (모바일), max 320px (데스크탑)
- 항목 클릭 시: 해당 섹션으로 `scrollIntoView({ behavior: 'smooth' })` + 사이드바 자동 닫힘
- 현재 보고 있는 섹션 하이라이트 (IntersectionObserver 기반)

### 본문
- 단일 페이지 스크롤 구조
- 각 대섹션(4개) 사이에 구분선
- 모바일 우선 반응형 (max-width: 640px 기준)

## 목차 구조 및 콘텐츠

### 1. 설치 / 로그인

#### 1-1. 앱 설치 (안드로이드)
1. Chrome 브라우저 접속
2. 주소창에 `posan.up.railway.app` 입력
3. 우측 상단 점 3개(⋮) 클릭
4. "홈 화면에 추가" → "설치" 클릭
5. 1~2분 후 설치 완료

#### 1-2. 앱 설치 (iOS)
1. Safari 브라우저 접속
2. 주소창에 `posan.up.railway.app` 입력
3. 하단(또는 상단)의 공유 아이콘(⎋) 클릭
4. "홈 화면에 추가" → "추가" 클릭
5. 1~2분 후 설치 완료

#### 1-3. 로그인 방법
- 교사: 개인 NEIS 아이디 / 초기 비밀번호 1234
- 학생: 이름 + 학번 5자리 (예: 김서현 / 10101)

#### 1-4. 비밀번호 변경
- 로그인 후 우측 상단의 "담임교사" 또는 "감독" 버튼으로 이동
- 설정에서 비밀번호 변경 가능
- 문의 시 관리자에게 연락

### 2. 감독교사

#### 2-1. 출석 체크 방법
- 좌석 1번 터치 → 초록(출석)
- 좌석 2번 터치 → 핑크(결석)
- 파란색 = 미체크 상태
- 종료 전 미체크가 없도록 모든 좌석 확인 필요
- 색상 칩을 UI에 시각적으로 표시

#### 2-2. 불참신청 승인
- 출석부 화면의 "불참신청" 탭에서 확인
- 신청 내역 확인 후 승인/거절 처리

#### 2-3. 감독교사 변경
- 감독일정 화면에서 교체 요청 가능

### 3. 담임교사

#### 3-1. 주간 출결 확인
- 담임 메인에서 자기반 학생 주간 출결 표시
- 각 셀에 호버링(터치)하면 출결 기록 사유 확인 가능

#### 3-2. 월간 출결 / Excel 다운로드 / 시수누계
- 월간출결 탭에서 월별 출결 통계 확인
- Excel 다운로드 버튼으로 데이터 내려받기
- 시수누계 컬럼으로 참여시간 검토

#### 3-3. 참여학생 관리
- 참여설정 탭에서 자기반 학생의 참여 여부 관리

#### 3-4. 불참사유 등록
- 불참사유 탭에서 학생별 불참 사유 등록

#### 3-5. 불참신청 승인
- 불참신청 탭에서 학생들의 신청 확인 및 승인/거절

#### 3-6. 감독일정 변경
- 감독일정 탭에서 자신의 감독 일정 확인 및 교체 요청

### 4. 학년관리

#### 4-1. 오늘출결 대시보드
- 메인 페이지에서 해당 학년 전체 오늘 출결 현황 확인

#### 4-2. 학생관리
- 학생관리 탭에서 사용자 등록, 수정
- 도우미 학생 선정 가능 (도우미는 불참신청 일괄 등록 권한)

#### 4-3. 참여설정
- 학년 전체에 대한 참여 설정 관리

#### 4-4. 좌석배치
- 좌석배치 탭에서 드래그앤드롭으로 좌석 배치

#### 4-5. 감독배정
- 월간 캘린더에서 감독교사 배정

#### 4-6. 월간출결 / Excel 다운로드
- 학년 전체 출석 데이터 조회
- Excel 다운로드 가능

## UI 스타일

- **테마**: 기존 앱 블루(#1e40af) 일관성 유지
- **섹션 헤더**: 연한 블루 배경(#eff6ff) + 좌측 블루 보더(3px, #2563eb)
- **단계 표시**: 번호 원형 뱃지 (배경 #dbeafe, 텍스트 #1e40af)
- **색상 설명**: 출석(#22c55e), 결석(#f472b6), 미체크(#3b82f6) 색상 칩 인라인 표시
- **타이포그래피**: 기존 Geist Sans 폰트 상속
- **반응형**: 모바일 우선, max-width 640px 기준

## 기술 구현

- `"use client"` 클라이언트 컴포넌트 (서버 데이터 불필요)
- `useState`로 사이드바 열림/닫힘 상태 관리
- `useRef` + `scrollIntoView({ behavior: 'smooth' })`로 목차 → 섹션 이동
- `useEffect` + `IntersectionObserver`로 현재 섹션 하이라이트
- CSS transition (`transform: translateX`)으로 사이드바 애니메이션
- Tailwind CSS만 사용 (외부 라이브러리 없음)
- 단일 파일 구현 (`src/app/help/page.tsx`)

## 범위 외

- 관리자(admin) 전용 기능 안내는 이번 범위에 포함하지 않음
- 학생 역할 안내도 이번 범위에 포함하지 않음 (필요 시 추후 추가)
- 검색 기능 없음
- 다국어 지원 없음
